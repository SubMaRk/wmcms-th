# Weimeng CMS (WMCMS) ระบบจัดการเนื้อหาสำเร็จรูป
  WMCMS เป็นระบบจัดการเนื้อหาสำเร็จรูป ก่อตั้งขั้นในเดือนมกราคมปีพุทธศักราช 2555 เป็นระบบที่ตั้งอยู่บนพื้นฐานของ PHP + MySQL ที่มุ่งในการพัฒนาให้ใช้ได้ฟรีและโอเพนซอร์ส ตัวระบบเน้นไปที่การจัดการนิยายเป็นหลัก โดยตัวระบบถูกสร้างขึ้นเพื่ออำนวยความสะดวกแก่ผู้ดูแลเว็บไซต์ ซึ่งสามารถจัดการส่วนต่าง ๆ ได้อย่างง่ายดายโดยที่ไม่ต้องทำระบบด้วยตนเอง ในส่วนของนักเขียนหรือนักแปลเองก็สามารถลงผลงานด้วยตนเอง รวมไปถึงหารายได้จากการเขียนหรือแปลจากผลงานได้โดยตรงด้วยระบบ VIP ที่สามารถซื้อเป็นบท เป็นเล่ม หรือทั้งเรื่องได้

# อัปเดทจาก 4.388.1021 เป็น V4.401.1047

## รายการอัพเดท
### เพิ่มใหม่ [ 13 รายการ ]
- โมดูลนักเขียนเพิ่มตัวเลือกโหมดรายได้ของนักเขียน (โหมดการชำระบัญชีรายได้ทางการเงินของนักเขียน)
- โมดูลนักเขียนเพิ่มระบบโหมดการชำระบัญชีรายได้ รายได้แต่ละรายการสามารถชำระบัญชีแยกได้ในหลังบ้าน และไม่โอนเข้าบัญชีนักเขียนโดยตรงอีกต่อไป
- เพิ่มการถอนเงินแบบผสมระหว่างยอดคงเหลือกับเหรียญทอง 2
- เพิ่มเทมเพลตหน้ารายละเอียดนักเขียนสำหรับผู้เยี่ยมชม
- เทมเพลตเริ่มต้นเพิ่มวิดเจ็ตสถิติของหน้าสร้างงานของนักเขียน
- บันทึกธุรกรรมทางการเงินของผู้ใช้เพิ่มจำนวนเหรียญทองก่อนและหลังทำรายการ
- กระแสเงินของผู้ใช้ในหลังบ้านเพิ่มการค้นหายอดคงเหลือก่อนและหลังทำรายการ
- เพิ่มการค้นหารายงานการขายและฟังก์ชั่นชำระบัญชีรายงาน
- เพิ่มการดูคำสั่งชำระบัญชีรายงานการขายในหลังบ้าน
- สถิติการชำระบัญชีเพิ่มจำนวนบท VIP ที่อัปเดตและจำนวนตัวอักษร VIP
- หน้านิยายเพิ่มป้ายกำกับจัดรูปแบบเนื้อหาบท และป้ายกำกับวนซ้ำรายบรรทัดของบท สามารถกำหนดป้ายกำกับเนื้อหาแต่ละบรรทัดเองได้
- เพิ่มไฟล์ AJAX สำหรับดึงจำนวนความคิดเห็นรายย่อหน้า "本章说"
- ปรับโครงสร้างหน้านิยายใหม่ หน้ารุ่นใหม่รองรับการตั้งค่าการอ่าน, 本章说 และฟังก์ชั่นดันมุ (รองรับเฉพาะเทมเพลต PC)

## รายการแก้ไข
### แก้ไข [ 26 รายการ ]
- แก้ไขป้ายกำกับนิยายที่ใช้งานไม่ได้
- แก้ไขการส่งลิงก์ไปยัง Baidu ที่ไม่เกิดข้อผิดพลาดแต่แจ้งเตือนว่าดึงจำนวนข้อผิดพลาดไม่ได้
- เพิ่มประสิทธิภาพการตรวจสอบตัวเลขในคลาสพินอิน
- หน้านิยายอ่านเพิ่มป้ายกำกับเวลาสร้างบท
- แก้ไขคำอธิบายการถอนเงินในการตั้งค่าการเงิน
- ปรับการแสดงข้อความยอดคงเหลือที่ถอนได้ในเทมเพลตถอนเงินและตรรกะการตรวจสอบคำขอถอนเงิน
- แก้ไขการจับคู่ฟิลด์ของป้ายกำกับ ID นักเขียนนิยายที่ผิดพลาด
- เพิ่มประสิทธิภาพการแก้ไขบทเก่าของนิยายให้อัปเดตชื่อแคชของบทล่าสุดพร้อมกัน
- แก้ไขการเปลี่ยนชื่อบทแรกที่ไม่ซิงก์ชื่อแคช
- เพิ่มประสิทธิภาพการแสดงชื่อนักเขียนในหน้ารายละเอียดนิยาย พร้อมเพิ่มลิงก์ไปยังหน้ารายละเอียดนักเขียน
- JS ส่วนกลางเพิ่มฟังก์ชั่นเต็มจอและออกจากเต็มจอ
- สถิติการชำระบัญชีเพิ่มอัตราแลกเปลี่ยนเป็นเงินหยวน
- คำขอทางการเงินเพิ่มอัตราแลกเปลี่ยน "梦宝" เป็นเงินหยวน ณ ขณะนั้น
- ปรับสิทธิ์เมนูลบและล้างบันทึกเงินให้อยู่ใต้หมวดที่เกี่ยวข้อง
- หลังบ้านเพิ่มการค้นหาข้อมูลบัญชีผู้ดูแลตาม ID
- คลาส wmsql.mysql เพิ่มเมธอดทรานแซกชัน
- แก้ไขหน้าแนะนำนิยายที่ไม่แทนที่สัญลักษณ์ขึ้นบรรทัดใหม่
- เปลี่ยนภาพพื้นหลังหน้าเข้าสู่ระบบหลังบ้าน
- เมธอด post เพิ่มการกำหนดค่าเริ่มต้น
- หน้าอ่านเพิ่มการห้ามคลิกขวา ห้ามเปิดโหมดดีบัก และห้ามเลือกลอกข้อความ
- ตารางความคิดเห็นเพิ่ม ID ชุดย่อยของเนื้อหาและ ID ย่อหน้าย่อย
- เพิ่มประสิทธิภาพไฟล์ดึงรายการความคิดเห็นให้เข้าถึงด้วย ID ย่อยได้
- หน้าอ่านเพิ่ม ID เล่มของบท และแทนที่ช่องว่างในเนื้อหาบทด้วยเอนทิตี
- JS ส่วนกลางเพิ่มเมธอดที่ใช้บ่อยสำหรับคุกกี้และเต็มจอ
- ข้อมูลผู้ใช้ไม่คืนค่าฟิลด์ salt รหัสผ่านแล้ว
- เพิ่มเมธอด AJAX สำหรับสมัครและยกเลิกการติดตามอัตโนมัติ
